# SHIELD website

Static site (HTML/CSS/JS, no build step).

## Publish on GitHub Pages
1. Create a new repository and upload everything from this folder (index.html must be in the root).
2. Settings -> Pages -> Source: "Deploy from a branch" -> branch `main`, folder `/ (root)`.
3. After a minute the site is live at `https://<user>.github.io/<repo>/`.

Pages: `index.html` (main), `cabinet.html` (client cabinet), `mobile.html` (phone preview frame).
